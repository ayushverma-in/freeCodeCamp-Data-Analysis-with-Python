# Mean-Variance-Standard Deviation Calculator

Takes a list of 9 numbers, arranges them into a 3x3 matrix, and calculates the mean, variance, standard deviation, max, min, and sum — across rows, columns, and the whole matrix.

## Tech Used
Python, NumPy

## How to Run
```bash
pip install -r requirements.txt
python main.py
```

## What I Learned
Reshaping data into NumPy arrays and running statistics along different axes (rows vs. columns) — a core skill for numerical data analysis.
