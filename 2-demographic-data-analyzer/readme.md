# Demographic Data Analyzer

Analyzes real 1994 US Census data using Pandas to answer questions about race distribution, education, income, work hours, and country-based income patterns.

## Tech Used
Python, Pandas

## How to Run
```bash
pip install -r requirements.txt
python main.py
```

## What I Learned
Filtering, grouping, and summarizing real-world tabular data with Pandas — the core workflow of practical data analysis.
