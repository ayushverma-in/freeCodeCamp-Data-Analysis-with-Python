# Medical Data Visualizer

Cleans and visualizes patient medical examination data to explore the relationship between lifestyle factors, body measurements, and cardiovascular disease using a categorical plot and a correlation heatmap.

## Tech Used
Python, Pandas, Matplotlib, Seaborn

## How to Run
```bash
pip install -r requirements.txt
python main.py
```

## Output
- `catplot.png` — compares healthy vs. unhealthy habits between patients with and without heart disease
- `heatmap.png` — shows correlation strength between all health factors

## What I Learned
Data cleaning (removing invalid entries) and building meaningful visual comparisons and correlation analysis with Seaborn.
