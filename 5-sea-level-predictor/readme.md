# Sea Level Predictor

Analyzes global average sea level data since 1880 and uses linear regression to predict sea level rise through 2050, comparing the long-term trend against the more recent (post-2000) rate of rise.

## Tech Used
Python, Pandas, Matplotlib, SciPy

## How to Run
```bash
pip install -r requirements.txt
python main.py
```

## Output
`sea_level_plot.png` — scatter plot of actual data with two projected trend lines to 2050

## What I Learned
Applying linear regression for real predictive modeling and comparing how trend windows (all-time vs. recent) affect forecasts.
