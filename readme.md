# freeCodeCamp — Data Analysis with Python

5 certification projects completed for freeCodeCamp's **Data Analysis with Python** course. Each project uses Python and real datasets to clean, analyze, and visualize data.

🎓 Certificate: [add your fcc certificate link here once claimed]

## Projects

| # | Project | What it does |
|---|---------|---------------|
| 1 | [Mean-Variance-Standard Deviation Calculator](./1-mean-variance-std-calculator) | Computes statistics on a 3x3 matrix using NumPy |
| 2 | [Demographic Data Analyzer](./2-demographic-data-analyzer) | Analyzes 1994 US Census data using Pandas |
| 3 | [Medical Data Visualizer](./3-medical-data-visualizer) | Visualizes patient health data with Seaborn charts |
| 4 | [Page View Time Series Visualizer](./4-page-view-time-series-visualizer) | Visualizes daily page-view trends over time |
| 5 | [Sea Level Predictor](./5-sea-level-predictor) | Predicts future sea level rise using linear regression |

## Tech Stack

Python, NumPy, Pandas, Matplotlib, Seaborn, SciPy

## How to Run

Each project folder is self-contained. To run any of them:

```bash
cd <project-folder>
pip install -r requirements.txt
python main.py
```
